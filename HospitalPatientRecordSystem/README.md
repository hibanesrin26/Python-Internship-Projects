# Hospital Patient Record System

## Description
A Python console-based Hospital Patient Record System using Object-Oriented Programming.

## Features
- Register patient
- Display patient records
- Search patient
- Update patient disease
- Delete patient
- Save patient records

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- person.py
- patient.py
- patient_manager.py
- file_manager.py
- patients.csv

## How to Run

python main.py
