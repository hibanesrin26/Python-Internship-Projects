# Expense Tracker

## Description
A Python console-based Expense Tracker using Object-Oriented Programming.

## Features
- Add expenses
- Display expenses
- Search expenses
- Delete expenses
- Categorize expenses
- Monthly expense summary
- Save records

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- transaction.py
- expense.py
- expense_manager.py
- file_manager.py
- expenses.csv

## How to Run

python main.py
