# Vehicle Rental Management System

## Description
A Python console-based Vehicle Rental Management System using Object-Oriented Programming.

## Features
- Add vehicle rentals
- Display rentals
- Search rentals
- Update rental days
- Delete rentals
- Calculate rental charges
- Save rental records

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- vehicle.py
- rental.py
- rental_manager.py
- file_manager.py
- rentals.csv

## How to Run

python main.py
