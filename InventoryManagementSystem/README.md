# Inventory Management System

## Description
This is a Python console-based Inventory Management System developed using Object-Oriented Programming concepts.

## Features
- Add Product
- Display Products
- Search Product
- Update Product Quantity
- Delete Product
- Save Products to CSV
- Load Products from CSV

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- product.py
- inventory.py
- inventory_manager.py
- file_manager.py
- products.csv

## How to Run
Run the following command:

```bash
python main.py
```
