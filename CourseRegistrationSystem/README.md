# Course Registration System

## Description
A Python console-based Course Registration System using Object-Oriented Programming.

## Features
- Add students
- Add courses
- Register courses
- Drop courses
- Display registrations
- Save registration data

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- person.py
- student.py
- course.py
- registration_manager.py
- file_manager.py
- registrations.csv

## How to Run

python main.py
