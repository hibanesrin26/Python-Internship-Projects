# Quiz Management System

## Description
A Python console-based Quiz Management System developed using Object-Oriented Programming concepts.

## Features
- Load questions from CSV file
- Conduct quiz
- Calculate score
- Save results to CSV

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Files
- main.py
- question.py
- quiz.py
- quiz_manager.py
- file_manager.py
- questions.csv
- results.csv

## How to Run

```bash
python main.py
```
